# Como usar no Antigravity IDE

Copie o conteúdo desta pasta para a raiz do seu projeto/pasta de desenvolvimento:

- `AGENTS.md`  → regras gerais (o Antigravity lê automaticamente se estiver na raiz do projeto ou acima)
- `.agents/skills/` → skills (carregadas dinamicamente quando o assunto aparece na conversa)

Para uso global em todos os projetos na mesma máquina: coloque na pasta `~/.gemini/config/` (`AGENTS.md` e `skills/`).

*Obs: Estes arquivos foram todos adaptados especialmente para a criação de uma landing page focada em conversão para um escritório de contabilidade (com 1 ou 2 contadores).*
