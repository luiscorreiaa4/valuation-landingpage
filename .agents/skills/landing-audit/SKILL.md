# Auditoria rápida de landing page de Contabilidade

## Como proceder
1. Leia o HTML/CSS/JS do projeto (ou a URL, se fornecida).
2. Verifique os 4 blocos abaixo com foco no nicho de serviços contábeis.
3. Entregue o resultado no formato de saída.

## O que verificar
**Performance**: Imagens (fotos dos profissionais, logos de clientes) grandes ou sem formato moderno, JS bloqueando a tela, scripts de terceiros (como widgets de chat) pesando o carregamento.
**SEO**: O `title` contém a palavra "Contabilidade" ou "Contador"? A `meta description` responde à dor do cliente? Há uso adequado de `h1` (só um) e `h2` para os serviços?
**Acessibilidade**: O contraste é suficiente para leitura confortável? As imagens possuem texto alternativo (`alt`)? Formulários e botões do WhatsApp são fáceis de clicar no celular?
**Conversão**: O CTA principal (ex: "Fale com um Contador") está visível acima da dobra? Os serviços estão claros sem uso excessivo de "contabilês"? A linguagem transmite segurança, proximidade (já que são apenas 1-2 contadores) e autoridade?

## Formato de saída
Lista curta, do maior impacto para o menor:

| # | Problema | Impacto | Correção |
|---|----------|---------|----------|

Termine com os **3 ajustes que mais valem a pena agora** para ajudar o escritório a conseguir mais leads contábeis.
